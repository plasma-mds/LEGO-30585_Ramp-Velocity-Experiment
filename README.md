# LEGO 30585 Ramp Velocity Experiment

This repository is a synthetic demonstration of experimental documentation for reproducibility. It shows how the level and completeness of documentation affect the ability to understand, evaluate, and reproduce existing results.

The materials use a LEGO 30585 vehicle as an illustrative case. The values and results are synthetic and are not physical measurements.

## Purpose

The repository contrasts complete records with deliberately incomplete variants. It brings together planning, provenance, laboratory records, data, analysis, figures, reporting, and metadata so that the role of each type of documentation in reproducibility can be examined.

The material was prepared for the 29th International School on Low Temperature Plasma Physics: Basics and Applications 2026.
